# Honey Helper — project notes for Claude

A small Stardew Valley SMAPI mod (C#) that stops flowers within a bee house's
range from being picked by hand, while leaving honey collection untouched.

## Development workflow

- **Trunk-based development.** Commit directly to `main`; do not create feature
  branches for routine work on this project.
- For a large or higher-risk change, propose a short-lived branch first — but the
  default is to work on the trunk.
